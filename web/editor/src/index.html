नेपाली र संस्कृतका लागि · Nepali and Sanskrit type

v1.000 · OFL-1.1 · weights 100–900

Typing studio

Weights

One variable file, any weight from 100 to 900.

Classical conjuncts

stacked forms Nagosi adds. Most Devanagari fonts break these with a visible halant (्); Sanskrit texts stack them.

Character set

Devanagari, Vedic signs, Latin with IAST, and both digit sets.

Use it

On the web, link the stylesheet. On phones and computers, install the TTF files.


      
    
        
  • Web cdn/nagosi.css loads only the scripts a page uses (Devanagari 127 KB, Latin 33 KB).
