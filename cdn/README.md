# @vedicnepali/font

Web font package. Files here are generated by `python font/scripts/build.py`; do not edit them.

```html
<!-- jsDelivr from GitHub, pinned to a release tag -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/sushilldhakal/font-keyboard@v1.0.1/cdn/vedicnepali.css">
<!-- or from npm -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@vedicnepali/font@1/vedicnepali.css">
<style>body { font-family: "Vedic Nepali", serif; }</style>
```

| File | What |
| --- | --- |
| `vedicnepali.css` | Variable font (weights 100–900) split by `unicode-range`: Devanagari 127 KB, Latin 33 KB, Latin Extended 36 KB. Browsers fetch only what a page uses. |
| `vedicnepali-static.css` | One WOFF2 per weight, for browsers without variable fonts. |
| `fonts/VedicNepali-Variable.woff2` | Whole variable font in one file (216 KB). |

Optional features: `font-feature-settings: "ss01"` Nepali forms (झ ५ ८ ९), `"ss02"` classical ल श,
`"ss03"` Sanskrit conjuncts (क्त क्र). `lang="ne"` and `lang="sa"` switch the language forms automatically.
