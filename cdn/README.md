# @nagosi/font

Web font package. Files here are generated by `python font/scripts/build.py`; do not edit them.

```html
<!-- jsDelivr from GitHub (pin a tag, e.g. @v1.0.0, in production) -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/sushilldhakal/font-keyboard@main/cdn/nagosi.css">
<!-- or from npm -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@nagosi/font@1/nagosi.css">
<style>body { font-family: "Nagosi", serif; }</style>
```

| File | What |
| --- | --- |
| `nagosi.css` | Variable font (weights 100–900) split by `unicode-range`: Devanagari 127 KB, Latin 33 KB, Latin Extended 36 KB. Browsers fetch only what a page uses. |
| `nagosi-static.css` | One WOFF2 per weight, for browsers without variable fonts. |
| `fonts/Nagosi-Variable.woff2` | Whole variable font in one file (216 KB). |

Optional features: `font-feature-settings: "ss01"` Nepali forms (झ ५ ८ ९), `"ss02"` classical ल श,
`"ss03"` Sanskrit conjuncts (क्त क्र). `lang="ne"` and `lang="sa"` switch the language forms automatically.
